# Meta

Maintaining the agent setup itself: auditing and bootstrapping harnesses, authoring skills, and filing improvements upstream.

## User-invoked

Run only when you type them.

- **[ask-harness](./ask-harness/SKILL.md)**: Find which skill or flow fits your situation.
- **[harness-builder](./harness-builder/SKILL.md)**: Analyze a codebase and recommend an agent harness.

## Model-invoked

You can type them, and the agent also reaches for them when a task fits.

- **[harness](./harness/SKILL.md)**: Audit, bootstrap, update, retro, or hoist an agent harness.
- **[harness-issue](./harness-issue/SKILL.md)**: File an issue or PR against the upstream harness repo.
- **[skill-writer](./skill-writer/SKILL.md)**: Write and review skills and agents in the house style.
