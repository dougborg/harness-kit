# A human docs page per skill

harness-kit does not keep a separate human-facing docs page for each skill.

## Why this is out of scope

Each skill's `SKILL.md` description says what it does and when to use it, and
each area's `README.md` lists its skills. A page per skill would be a second
copy of the same text, and `just check` can only keep the README lists in
sync, not prose copies.
